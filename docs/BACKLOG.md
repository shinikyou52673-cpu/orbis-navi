## 実走での確認待ち（Web調査では絞り込めなかったもの）

- **声でメモ（2026-11-10追加）がiPhoneのChromeで動くか**：走行記録の `voice` イベントで確認する
  - `ev:'heard'` がある → 聞き取れている
  - `ev:'error'` の `err` が `not-allowed` / `service-not-allowed` → ブラウザが音声認識を許可していない。Siriのショートカットで送る方式を提案する
  - `ev:'restart'` が多い → iPhoneの聞き取りが固まっている
  - メモの `via:'voice'` の文面が崩れていれば、`VM_START` / `VM_END` の言い方を足す
  - 音楽が止まる苦情があれば、マイクの常時使用が原因（iPhoneの仕様）
