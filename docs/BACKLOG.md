## 使い勝手（利用者の指摘・2026-11-09）

- 対応済み（2026-11-09）
  - 音楽が止まる → 音の出し方の設定を追加（初期値「鳴らさない」）
  - 再検索がUターン指示 → 向きを必ず指定し、Uターン始まりは前方から取り直す
  - 逆走しても案内が進む → 逆走判定を追加
- 一部対応（2026-11-13）：**ルートの質が微妙**
  - 都内の区間で実測し、原因を2つ直した（国道の大回り → `use_distance:0.3`、「高速を使わない」で国道まで避ける → `use_tolls:0` に変更）
  - 有料を使う候補しか無いときは、下道の候補も並べるようにした（前回どちらで走ったかを覚える）
  - 残り：利用者の実走での評価。走行記録・改善メモが届いたら、どの区間のどんな選び方が不満だったかを分析する
- 未解決：**メモ・走行記録が送信先に届かない**（2026-11-13 時点で、届いたのは送信テスト1件だけ）
  - 送信先の設定はブラウザごとに別。利用者が走行に使うブラウザに設定が入っていない可能性が高い（設定を移すリンクを追加した）
  - 届き始めたら、この項目を消す
- 未解決：**声でメモ（アプリ内の聞き取り）がiPhoneのChromeで動かない**
  - 利用者のテスト結果は「マイク：反応あり／音声認識：aborted」。ただしこのときのテストは、マイクの音量測定の直後に音声認識を始める作りで、結果が当てにならない（2026-11-13 に順番を直した）
  - 次に届く `diag/` の `srEvents` を見る：`soundstart` があれば音は届いている／`error:service-not-allowed` ならiPhone側で音声認識が許可されていない／`timeout` だけなら音が届いていない
  - Bluetoothのインカムは、マイクを使う間は通話用の接続になり、音楽の音質が下がる。音楽と両立させるなら「Siriでメモ」（設定に手順あり）
